# Архив FastAPI

Это исходники предыдущей Python/FastAPI-версии API, сохранённые только для истории миграции.

Рабочий backend AirPulse находится в `services/api/src`, написан на NestJS и запускается Node-контейнером из `services/api/Dockerfile`. Архив не копируется в Docker-образ и не используется системой.
